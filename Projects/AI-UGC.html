How it works

The problem this solves

Any image model can generate a good-looking person. The hard part is generating the same person hundreds of times, in different places, clothes and lighting, so an audience believes it is one individual. Most tools try to do this by showing the model a reference photo with every request. That works for two or three images and then the face starts to change. In the one independent side-by-side test I found, Google's Nano Banana had lost the subject's likeness by the third image in a row.

The tools that do hold a face all use the same method underneath: they train a small add-on model on 20 to 30 photos of the character. The add-on is called a LoRA. Once it exists, every generation starts from the character's face instead of guessing it from a reference. Higgsfield sells this as "Soul ID" for $19 to $59 a month and keeps the trained model on their servers. On fal.ai the same training job costs about $2 and gives you a file you can download and keep.

Step by step, in plain words

  1. Describe the character. One line in character.txt: age, hair, skin, two small distinctive marks like freckles or a nose stud. The marks matter because they give the model something specific to lock on to.
  2. Generate 12 faces and pick one. The script makes 12 portraits from that line. I choose the one I'd follow. That photo becomes the base.
  3. Make 24 photos of that same face. An edit model takes the base photo and changes one thing at a time: angle, expression, outfit, lighting, full body, close-up. The face stays the same. I delete any where it didn't.
  4. Train the LoRA. The 20 to 30 approved photos are zipped and uploaded. About five minutes and $2 later a small file comes back. That file is the character. I back it up.
  5. Make posts. I write one line per post in scenes.txt: what they're wearing, where they are, what they're doing, the camera angle, the light. The script generates each one with the LoRA applied, so it's always the same person. About 3.5 cents a photo.
  6. Make a talking video. I write what the character says in script.txt. ElevenLabs reads it in the character's fixed voice. Kling's avatar model then animates one of the photos to match the audio. Video models can't use the LoRA directly, so the photo is what carries the face into video.

Why I wrote code instead of paying for a platform

Platforms like Higgsfield do the same thing with a nicer interface. I rejected them for three reasons. The character lives on their server, so if they ban the account or shut down the character is gone. The credits expire monthly whether I use them or not. And the price jumps from $19 to $59 the moment I want more than a few posts a week. The script costs about $2 a month at 10 posts a week and about $7 at 50, and the character is a file I can move anywhere.

What doesn't work yet

  • The LoRA drifts slowly after a few hundred images. The fix is monthly: add the best new photos to the training set and retrain for $2. The character gets sharper over time rather than blurrier.
  • Lip-sync needs a front-facing photo with the mouth closed and shoulders visible. Side profiles and laughing shots come out wrong.
  • Hands are still unreliable. Scenes are written so the hands are holding something or out of frame.
  • An undisclosed AI persona selling products is a problem under India's ASCI guidelines and Meta's AI-content labelling. The account says "AI creator" in the bio from the first post.

Setting it up

About 20 minutes before the first run, then one evening to create the character. You need Python 3.10 or newer; check with python3 --version.

1

Get two keys

fal.ai → sign up → Billing → add $10 → Keys → create one. elevenlabs.io → sign up (free) → profile → API Keys → create one. On ElevenLabs also open Voices → Library, add one voice to your library, and copy its voice ID.

2

Install

unzip ai-influencer-kit.zip && cd ai-influencer-kit
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
3

Fill in .env

Open it in any editor. One value per line, no quotes.

FAL_KEY=your_fal_key
ELEVENLABS_API_KEY=your_elevenlabs_key
VOICE=your_voice_id
TRIGGER_WORD=mira_v1
4

Create the character

Edit the one line in character.txt, then:

python 1_make_refs.py faces      # pick one face, copy it to refs/base.png
python 1_make_refs.py train      # delete any photo where the face drifted
python 2_train.py                # back up the file it saves in lora/
5

Make content

Edit scenes.txt and script.txt, then:

python 3_post.py
python 4_video.py out/<batch>/<photo>.jpg script.txt

Keepers from out/ go to Instagram. cost_log.csv shows what you've spent.
